K8s Agent Arena

A Reproducible Benchmark for LLM Agents Operating Kubernetes Clusters

About

K8s Agent Arena is a reproducible benchmark for LLM agents operating Kubernetes clusters. It grades the cluster, not the agent's self-report, and scores blast radius alongside task success.

This benchmark ensures fair, objective evaluation of LLM agent capabilities in real Kubernetes environments.
